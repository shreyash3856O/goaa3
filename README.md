# HH Goa 2026 — Editorial Shoreline Edition 🌊

A calm, photographic, travel-editorial single-page web app for **HH Goa 2026** hackathon participants to generate official profile pictures for X (Twitter).

---

## Visual Design & Signature Features

- 📖 **Editorial Photo-Stack Card**: A tall rounded card holding stacked full-bleed panels with soft-serif captions (`Fraunces` typeface).
- 🎨 **Natural Palette Presets**: Muted, photographic tone options including Forest Sand, Ocean Lagoon, Shore Sunset, and Deep Ink.
- 📸 **Live Webcam Stream**: Take selfies directly inside the browser.
- 🍏 **iPhone HEIC Support**: Automatic client-side conversion for Apple `.HEIC` photos via `heic2any`.
- 🐦 **Direct X Share Flow**: Auto-downloads 1200x1200 PNG and copies image to clipboard for instant `Ctrl + V` pasting into Twitter composer.
